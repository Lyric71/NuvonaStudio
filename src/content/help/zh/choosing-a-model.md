Nuvora 替你写帖子、回答问题时，执笔的是一个 AI 模型。你不必叫得出各个模型的名字也能做选择：每个模型选择器都先给出三个简单选项，**快速**、**均衡** 和 **旗舰**，完整列表也只差一次点击。

## 在哪里选择模型

凡是 AI 撰写文字的地方，都有模型选择器：

- 帖子的简报里，**语言** 旁边，供 **AI 起草** 使用；
- 帖子文案步骤中的 **再写一版**；
- 选中一段文字并点击 **用 AI 重写** 后弹出的菜单；
- [提问](/zh/help/ask) 页面，**使用技能** 旁边。

智能体另有设置方式：每个智能体在自己的表单里都有单独的 **模型** 字段。参见 [智能体](/zh/help/agents)。

## 按钮

选择器就是一个紧凑的按钮，显示你当前的选择：如果模型属于三个选项之一，先显示该选项的图标和名称，接着是模型名称，最后是这项功能典型运行一次的费用。

点击按钮，打开 **选择模型**。按 Esc 键、点击外部区域或做出选择，都会将它关闭。用键盘操作时，方向键可在各个选项之间移动。

如果只有一个模型可用，就没有按钮，只有一行 **运行于**，后接模型名称。

## 快速、均衡和旗舰

**选择模型** 的上方以卡片形式列出三个选项：

| 选项 | 卡片上的说明 |
|---|---|
| **快速** | 速度快、成本低，适合草稿和短帖 |
| **均衡** | 质量可靠、价格适中，适合大多数工作 |
| **旗舰** | 能力最强，适合重要工作和疑难问题 |

每张卡片都显示它所用的模型；该模型能联网搜索时带一个地球图标，能识别图片时带一个图片图标；旁边是价格，下方注明 **每次运行**。带 **此处推荐** 星标的，就是无人选择时这项功能使用的模型。

每个选项用哪个模型，由 Nuvora 决定，并可能随新模型上线而调整，所以一切以卡片显示为准。如果某个选项的模型被团队禁用，或被你在 **我的模型** 中关闭，这个选项会改用你可用的、价格最接近的模型。快速优先在更便宜的模型里找，旗舰优先在更强、更贵的模型里找，因此快速始终便宜，旗舰始终强劲。

这项功能的推荐模型一定在三个选项之中：它会取代价格与之最接近的那个选项，星标也落在那张卡片上。两个选项绝不会显示同一个模型，所以只有一两个模型可用时，你只会看到一两个选项。

在提问页面，**联网搜索** 开关处于开时，选择器只提供能联网搜索的模型，模型不能搜索的选项也会从卡片中消失。

## 全部模型

卡片下方是 **全部模型**，旁边标着模型数量，点开即是完整列表：你在此处能用的每个模型，按提供商分组，各自标明每次运行的费用，以及同样的联网和图片图标。带 **默认** 标签的，就是无人选择时使用的模型。

在 **搜索模型或提供商** 中输入文字，即可缩小列表范围。没有结果时，会显示“没有匹配的模型。”

如果你当前用的模型不在三个选项之中，打开时 **全部模型** 就已经展开。

右上角的 **比较模型** 会在新标签页中打开 [模型基准测试](#模型基准测试) 页面。

## 每次运行的费用

按钮、卡片和列表上的价格，是这项功能典型运行一次时你的团队要付的全部费用：在简报里是一条帖子，在提问里是一个回答。简报或对话越长，花费越多；越短，花费越少。每次运行的实际价格会显示在运行结果上，并按显示的金额扣费。参见 [余额与付款](/zh/help/balance-and-payments)。

## 你的选择会被记住

Nuvora 会在这个浏览器上分别记住你在每项功能中的选择：起草帖子用的模型和提问时用的模型，各记各的。换一个浏览器或一台电脑，选择器会从推荐模型开始。

选择标着 **默认** 的模型（带星标的卡片，或带 **默认** 标签的那一行），就会重新跟随默认设置：日后 Nuvora 调整默认模型，你的运行也会随之改变。

如果你在 **我的模型** 中关闭了某项功能的默认模型，选择器会从你保留的第一个模型开始。记住的模型如果已不再提供，就会被自动忘掉。参见 [账户与登录](/zh/help/account-and-sign-in#我的模型)。

## 模型基准测试

**模型基准测试** 页面展示各个文本模型在公开基准测试中的表现，供你在三个选项不足以拿定主意时参考。可以从任意选择器中的 **比较模型** 打开，也可以从 **设置** 里 **我的模型** 卡片上的 **通过公开基准测试比较模型** 链接打开。

页面最上方是三个选项的卡片。每张卡片显示 **运行于** 和模型名称，或者 **此处不可用**；接着是价格档位，从 $ 到 $$$$，表示这个模型与其他模型相比有多贵；最后是一条帖子的大致费用（“每条帖子约……”）。

### 得分与费用

**得分与费用** 列出你的团队允许使用的文本模型，默认按 Intelligence Index 从高到低排列。用 **提供商** 可以只看某一家厂商的模型，选 **全部提供商** 则重新显示全部。点击某一列即可按该列排序：得分从高到低，价格和费用从低到高，再点一次则顺序反转。没有数据的模型始终排在最后。

| 列 | 显示内容 |
|---|---|
| **模型** | 模型名称和提供商，它所对应的选项（**快速**、**均衡** 或 **旗舰**），以及 **可联网搜索** 和 **可识别图片** 图标。 |
| **价格** | 价格档位，从 $ 到 $$$$。 |
| **Intelligence Index** | Artificial Analysis 的综合得分，汇总了推理、知识、编程和智能体任务方面的十项高难度测试。 |
| **LMArena Text** | 根据大量盲测投票得出的评分：用户在两个回答中选出更好的一个。 |
| **Output speed** | 模型开始作答后，每秒写出的 token 数，大致相当于词数。 |
| **Humanity's Last Exam** | 约 2000 道横跨多个领域的高难度专家级题目，不借助工具作答。 |
| **GPQA Diamond** | 研究生水平的科学题，即使上网搜索也很难答出。 |
| **tau2-bench Telecom** | 一段客服对话，模型必须正确使用工具并遵守规则。 |
| **一条帖子** | 你的团队写一条 LinkedIn 帖子的全包费用。 |
| **一篇文章** | 你的团队写一篇长文章的全包费用。 |

每个得分都链接到它的来源页面。小写的“v”表示这是模型厂商自己公布的数字，因为没有独立数据。短横线表示没有公开数据：我们从不估算任何得分。最新的模型在 GPQA Diamond 和 tau2-bench Telecom 两列显示短横线，因为这两项测试已不再用于它们。

标题下方有一行写明得分的采集日期（“得分采集于”加日期）。得分大约每月更新两次。

费用是你的团队为一次典型运行支付的金额。实际运行时，简报长就贵一些，短就便宜一些。

### 各项基准测试衡量什么

最后一张卡片 **各项基准测试衡量什么** 逐一解释每项基准测试，并附上来源链接。某项测试得分高，并不代表模型样样都强：撰写营销文案时，请优先参考综合指数和竞技场排名，后者由用户投票选出更喜欢的回答。

这个页面只列文本模型，生成图片的模型不在其中。

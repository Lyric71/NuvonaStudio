**日志** 是你在 Nuvora 里的个人记录。一张表里汇齐了 Nuvora 替你生成的草稿、配图和帖子，发给你的通知，你的智能体的运行，寄到你邮箱的邮件，你这个登录账号的每一次登录，以及记在你名下的每一笔付费操作。想确认一条排期帖子到底发出去没有，想知道你不在时什么失败了，想看看昨晚是哪个浏览器登录的，或者想查一份草稿花了多少，来这里查。

页面顶部的 **动态** 只管眼下在跑的和最近一天结束的任务，更长的历史归日志。它和 **账户设置** 里的 **操作日志** 是两回事：那张卡片用图表展示钱花在了哪里。

## 打开日志

点右上角的头像，再点 **日志**。页面标题上方写着 **您的记录**。

另有两条路通到这里：

- **动态** 面板底部的 **在日志中查看全部**；
- 汇总未读通知的那张卡片上的 **更多** 按钮（见 [回来时通知堆成一摞](/zh/help/log#回来时通知堆成一摞)）。

## 六个分区

页面标题下方的标签决定表格显示什么，每个标签旁都标着它在所选周期内的行数：

| 分区 | 列出的内容 |
|---|---|
| **全部** | 下面五个分区合成一张表。 |
| **运行与通知** | **动态** 通知过你的每一项任务：你发起的草稿和帖子配图，以及你不在时自行发生的事，比如一条排期帖子发了出去或发送失败。你从 **动态** 里清除的行，这里照样留着。 |
| **智能体** | 你自己的智能体的运行，以及你用 **立即运行** 亲手发起的运行。 |
| **邮件** | Nuvora 发到你邮箱的邮件：登录验证码、汇总、摘要、提醒等等。 |
| **登录记录** | 你这个登录账号的每一次 **已登录**、**登录被拒**、**已登出** 和 **已申请重置密码**。 |
| **支出** | 记在你名下的每一笔付费操作，按实际计费金额列出。 |

## 读懂这张表

每一行是一件事，分八列：

| 列 | 内容 |
|---|---|
| **时间** | 日期和时刻，格式随你的日期与时间设置。 |
| **分类** | **运行记录**、**智能体**、**邮件**、**登录记录** 或 **支出**。 |
| **类型** | 运行沿用 **动态** 里的类型，比如 **社交媒体帖子**、**帖子配图** 或 **发布**；其他行标为 **智能体运行**、**邮件**、**登录** 或 **付费操作**。 |
| **内容** | 任务名称、智能体名称、邮件主题、登录事件或付费操作的名称。 |
| **状态** | 运行和智能体运行是 **已完成**、**失败** 或 **运行中**；邮件是 **已发送** 或 **未发送**；登录是 **成功** 或 **被拒**；付费操作是 **已计费**。 |
| **详情** | 运行的结果或错误信息、智能体这次运行的发现、邮件没有发出的原因、登录时的浏览器、系统、地点和 IP 地址（“Chrome · Windows”），或者付费操作调用模型用掉的 token 数。 |
| **时长** | 一次运行或一次智能体运行用了多久。 |
| **计费金额** | 一笔付费操作，或一次计费的智能体运行，花了你多少。 |

表格上方有一行汇总，概括筛选后留下的内容，比如“133 行 · 14 项失败 · 计费 $0.03”。点击列标题，表格就按这一列排序；再点一次，顺序倒过来。空白的格子一律排在最后。

## 缩小范围

- **周期**，在页面右上角：**今天**、**最近 7 天**、**最近 30 天**（默认）、**最近 90 天** 或 **过去 12 个月**。
- **状态**，在标签旁边：**全部状态**、**成功**、**失败** 或 **运行中**。选 **失败**，留下失败的任务和智能体运行、没有发出的邮件和被拒的登录。
- **类型**：**所有类型**，或者当前分区里出现过的某一类。
- **搜索日志**：只留下名称、详情、类型或状态里含有你所输入词语的行。

表格每页 100 行。表格下方的翻页栏写明当前位置（“第 1 至 100 行，共 133 行”），并提供 **上一页**、页码和 **下一页**。页面地址会记住周期、分区、筛选、排序和页码，刷新或从书签打开，看到的仍是同一个视图。

所选周期内的记录一次全部载入，每个分区上限 1000 行。超出时，汇总行会加上一句：“该时段的记录超出日志一次可显示的数量。请选择更短的时段以查看全部。”

**周期** 旁边的 **导出 CSV**，把筛选后留下的所有行（不分页）存成一份表格文件，数值都是原始格式，方便求和：时间用 ISO 格式，时长以秒计，计费金额以美元计。

## 打开一行

- 运行：打开它所属的页面，和 **动态** 里的行一样。
- 智能体运行：打开智能体的 **运行记录** 标签页，并定位到这一次运行。参见 [智能体](/zh/help/agents)。
- 邮件：正文在这一行下方展开，再点一次主题收起。
- 登录记录和付费操作：没有可去的地方，该知道的都写在这一行上。

能打开你账户的邮件（登录验证码、重置密码、注册验证码、欢迎邮件和各类邀请）照样列出主题和时间，但从不显示正文，点开只会看到：“这封邮件含有登录验证码或账户链接，因此这里不保留正文。”这样一来，即使你在公用电脑上忘了退出，别人也没法借此拿到你的密码。

## 回来时通知堆成一摞

你不在时结束的任务，会在你下次打开 Nuvora 时逐一通知，每项一张卡片，出现在屏幕右下角。超过五项时，只有最新的五项各占一张卡片，最后再压上一张汇总卡：**您离开期间**，“另有 12 条通知”（数字以实际为准），外加一个打开日志的 **更多** 按钮。

这些通知一次性全部算作已读，换一页也不会再来第二波。它们都在 **运行与通知** 里等着你。

## 谁能看到你的日志

只有你自己。日志只读取你本人的行，不管来查的人是什么角色，团队管理员也一样。不过，管理员从 **团队** 打开你的个人页面，仍能看到你最近几次登录，那是另一个页面。

客户登录没有日志。在他们那边，未读通知的汇总卡只显示数字，没有 **更多** 按钮。

日志在权限里有自己的一行 **日志**，归在 **共享** 下，除客户以外的所有角色一开始就有：“本人的记录：运行、通知、智能体运行、收到的邮件、登录记录和付费操作。只需查看权限，其他人无法看到。”管理员要是收回某人的这项权限，**日志** 就从他的菜单里消失，**动态** 也不再显示 **在日志中查看全部**，汇总卡上只剩数字。参见 [你的团队](/zh/help/your-team)。

## 费用

看日志和导出日志都不花钱。**支出** 逐笔列出你的付费操作花了多少；**账户设置** 里的 **操作日志** 把它们汇总起来。参见 [余额与付款](/zh/help/balance-and-payments)。
